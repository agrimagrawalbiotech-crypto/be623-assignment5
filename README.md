This is the repository containing all required data to complete assignment 5 of BE623. 
Download Assignment_5.R and run anywhere to analyze expression of PER2 and BMAL1 genes. 


Agrim_BE623_Assignment_5.Rmd file is the R MARKDOWN file which is used to build the pdf directly from inside RStudio. 

assignment_5.R is the R script used to run the pipeline required for the assignment questions. 

circadian_expression.csv is the expression data for each of PER2 and BMAL1 genes. 

There are also Boxplot and scatter plots for the expression values of these 2 genes based on ZT (Zeitegeber time in h)
